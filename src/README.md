# Codice applicativo

`app/`: shell e navigazione hash; `features/`: schermate; `components/`: campi accessibili; `domain/`: validazione pura; `services/`: messaggi di errore; `storage/`: IndexedDB e transazioni. Nessun backend o storico fittizio.

Leggere [ARCHITECTURE](../docs/ARCHITECTURE.md), [DATA_MODEL](../docs/DATA_MODEL.md) e [stato](../docs/PROJECT_STATUS.md) prima di estendere i moduli.
